## ⚡ Overview

This repository houses the source code for the personal engineering portfolio of **Joshua Jose**. Designed from the ground up to reject standard cookie-cutter templates, the site employs an **Electric Cyber Amethyst on Obsidian** aesthetic inspired by quantum cryptography, aerospace HUD consoles, and futuristic developer interfaces.

### 🌟 Key Architectural Highlights

* 🌌 **Multi-Layer Parallax Engine**: Integrated with [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll) and [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/) for buttery smooth scrolling, inertia dampening, and velocity-based animations.
* ✨ **Dynamic Canvas Starfield**: A standalone 2D canvas background that renders animated, twinkling star clusters with dynamic resize recalculations.
* 🎥 **Cinematic Video Integration**: High-definition walking video layer with non-blocking CSS blend overlays and responsive mobile optimizations.
* 🃏 **Stacking Card Deck (Section 03)**: Physics-inspired project cards that pin, stack, and pop-out as the user scrolls, featuring video embeds, tool tags, and GitHub references.
* 🎖️ **Interactive Credential Hub (Section 04)**: Dynamic accordions for accredited coursework spanning IBM, Oracle Cloud, Cisco, and Intel with custom modal preview architecture.
* 🛡️ **Establish Handshake HUD (Section 05)**: A custom cryptographic-styled dispatch console (`// IDENTITY`, `// RETURN_ADDRESS`, `// ENCRYPTED_MESSAGE`) with automated 256-bit simulation logging and real-time validation.
* 🤖 **Autonomous AI Terminal & Chatbot**: Built-in chatbot widget capable of answering recruiter questions regarding Joshua's background, skill inventory, and technical projects.

## 💻 Local Setup & Development

To run and inspect this project locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/joshua5915g/my-portfolio.git
   cd my-portfolio
   ```

2. **Serve the Project**:
   Since the project uses modern ES modules and video assets, run a local web server:

   *Using Python 3:*
   ```bash
   python -m http.server 3000
   ```
   *Using Node.js / npx:*
   ```bash
   npx serve .
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:3000/` in your browser.
